# MarkShotHis

独立的截图、剪贴板历史和贴图工具。它不依赖 MarkNotePro、MarkTextPro 的窗口或进程，也不会修改这两个项目的数据。启动后不显示主窗口，仅在系统托盘或 macOS 菜单栏显示入口。

## 功能

- 截图：鼠标拖动选区，可画笔、矩形、箭头、文本、序号、标签标注；支持复制、保存和贴图。
- 剪贴板历史：记录文字和图片，可搜索、复制、删除、清空，图片可直接贴图。
- 贴图：显示剪贴板图片或历史图片，支持画笔、矩形、文字编辑及复制、保存。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 截图 | Control + Shift + 1 |
| 剪贴板历史 | Control/Command + Shift + F3；Control + Shift + 3 |
| 贴图当前剪贴板图片 | 托盘菜单 |

若快捷键被其他应用占用，可从托盘菜单启动对应功能。截图和贴图窗口可按 Escape 关闭。

## 开发和打包

需要 Node.js。运行 npm install 安装依赖，npm run dev 启动开发版。macOS 用 npm run build:mac 生成 DMG 和 ZIP；Windows 用 npm run build:win；Linux 用 npm run build:linux。跨平台目标已配置，但需在目标系统上分别验证截图权限和窗口行为。

macOS 首次截图需授予“屏幕与系统音频录制”权限。第三方应用全屏空间下的中文输入法候选栏行为依赖系统窗口管理，必须在真实多屏全屏场景下测试，不能仅凭代码检查认定已解决。

剪贴板历史保存在应用自己的用户数据目录中。最多保留 200 条、图片总量约 300 MB；单张超过 20 MB 或 2500 万像素的图片不记录。应用使用单实例运行，关闭所有工具窗口不会退出，需通过托盘菜单退出。
