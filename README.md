# MarkShotHis

MarkShotHis 是独立的截图、剪贴板历史和贴图托盘工具。它从 MarkNotePro 的相应模块拆出，不需要同时运行 MarkNotePro 或 MarkTextPro。应用没有笔记主窗口；关闭工具窗口后仍在后台运行，须通过托盘菜单退出。当前版本为 `0.2.0`。

本项目不包含 Markdown 编辑器、draw.io、GeoGebra、思维导图或 PDF 编辑器。

## 功能

| 功能 | 当前实现 |
| --- | --- |
| 截图 | 以鼠标所在显示器为目标，拖动选择区域；提供矩形、椭圆、直线、箭头、画笔、文字、标签、序号、序号说明、马赛克/模糊、高亮、荧光笔和水印等标注。支持撤销、复制、保存 PNG、生成贴图。 |
| 剪贴板历史 | 后台记录文字和图片，列表支持搜索、按图片/文本筛选、预览、复制、删除和清空。双击或回车可复制所选条目并关闭窗口。文件复制不记入历史。 |
| 贴图 | 可从截图或历史条目创建。图片贴图支持移动、缩放、置顶切换、复制、保存和编辑标注；历史文本也可创建文本贴图。 |
| 外观 | 在托盘菜单切换浅色/深色主题及语言。界面支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语。 |

截图复制、保存或贴图后会写入历史。历史最多保留 500 条，同内容的再次复制会移到最新位置。删除图片记录或清空历史会删除相应本地图片文件，请先保存需要长期保留的内容。

## 入口与快捷键

启动后通过系统托盘（macOS 菜单栏）操作。macOS 不显示 Dock 主窗口；再次启动会复用已有实例并打开历史窗口。

| 操作 | 全局快捷键 |
| --- | --- |
| 截图 | `Control+Shift+1` |
| 打开/关闭剪贴板历史 | `Control+Shift+3` |

贴图从截图工具栏或历史条目中创建，没有单独的全局快捷键。快捷键若被其他应用占用，注册可能失败，可使用托盘菜单。历史窗口支持方向键选择、回车复制和 `Esc` 关闭。

## 数据与互通

- 剪贴板记录：`~/.mark-suite/clipboard/history.json`
- 图片文件：`~/.mark-suite/clipboard/images/`
- 本应用主题与语言设置：Electron 的 MarkShotHis `userData/settings.json`

历史目录与 MarkNotePro、MarkTextPro 共用，应用会监听历史文件变化。首次启动时会读取 MarkNotePro 的主题和语言偏好；在 MarkShotHis 托盘菜单修改后，设置保存到本应用文件，**不会反向修改其他应用的偏好**。多个应用同时写共享历史文件没有跨进程事务保护，可能互相覆盖；尤其避免同时删除或清空历史。

历史数据保存在本机，不由本项目上传至服务端。剪贴板中可能包含密码或令牌，请留意共享电脑上的数据保留。

## 开发与构建

需要 Node.js、npm 和对应平台的图形桌面环境。在项目根目录运行：

```bash
npm ci
npm run dev
```

| 平台 | 构建命令 | 配置的产物 |
| --- | --- | --- |
| macOS | `npm run build:mac` | DMG、ZIP |
| Windows | `npm run build:win` | NSIS 安装包 |
| Linux | `npm run build:linux` | AppImage、DEB |

产物默认在 `dist/`。项目使用 Electron、Vue 3 和 electron-vite。`src/main/` 管理托盘、全局快捷键、剪贴板、截图和窗口，`src/renderer/src/pages/` 是各工具界面，`src/preload/` 提供 IPC 桥接。构建脚本已配置三个平台，但 Windows/Linux 的截图权限、托盘和窗口行为仍需在对应系统实测。

## 已知边界

- macOS 首次截图需授予“屏幕与系统音频录制”权限；授权后通常需要完全退出并重启应用。
- macOS 第三方应用全屏空间、多显示器和中文输入法候选栏行为依赖系统窗口管理，需在实际环境验证截图文字输入及贴图编辑。
- Windows/Linux 截图使用 Electron `desktopCapturer`；macOS 优先使用系统 `screencapture`。部分 Linux 桌面环境可能需要额外的截图或托盘支持。
- 关闭截图、历史或贴图窗口不会停止后台剪贴板监控；退出请使用托盘菜单。
